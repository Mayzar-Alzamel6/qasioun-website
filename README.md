# قالب منيو QR للمطاعم

منيو رقمي للصالة: الزبون بيمسح QR على الطاولة، بيشوف المنيو، بيختار طلبه، وبيبعته على واتساب المطعم مع رقم الطاولة.
موقع ثابت (HTML/CSS/JS) بدون أي build — بينرفع على GitHub Pages أو Netlify كما هو.

## تجهيزه لمطعم جديد

| الملف | شو بتعدّل فيه |
|---|---|
| `js/site-config.js` | الاسم، الشعار، العبارة، العنوان، الدوام، الأرقام، **رقم واتساب الطلبات**، روابط السوشال، العملة، الألوان |
| `js/menu-data.js` | الأقسام والأصناف والأسعار (الشرح بأول الملف) |
| `index.html` (بالـ `<head>` بس) | `<title>` و `meta description` و `og:*` — لأن واتساب وفيسبوك ما بيشغّلوا JS لما يعرضوا معاينة الرابط |
| `assets/favicon/` | أيقونة المتصفح وصورة المشاركة `og-image.jpg` |

- **الشعار:** حط الصورة (مربعة، WebP/PNG) بـ `assets/img/logo/` واكتب مسارها بـ `logo`. إذا تركته فاضي بيطلع دائرة ذهبية فيها أول حرف من `shortName`.
- **صور الأقسام:** اختيارية — `img: 'assets/img/menu/pizza.webp'`، وبدونها بيطلع `icon` (إيموجي) على خلفية بألوان الهوية.

## روابط QR للطاولات

كل طاولة إلها رابط برقمها، مثلاً طاولة 5:

```
https://<الموقع>/?t=5#menu
```

الرابط بيفتح المنيو مباشرة وبيعبّي رقم الطاولة بالطلب تلقائياً.

## حركة الـ Hero

صور مراحل البيتزا بـ `assets/img/hero/`. لتوليد نسخ جديدة: حط الصور الخام (خلفية خضراء `#00FF00`) بـ `assets/img/hero/raw/` وشغّل:

```
python scripts/remove_green_screen.py
```
